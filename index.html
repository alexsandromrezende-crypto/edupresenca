Como funciona

Registre uma situação de frequência por estudante e por dia letivo: presente, falta não justificada ou falta justificada. O sistema calcula a sequência de faltas não justificadas nas datas registradas, em ordem cronológica. Ao atingir 4 faltas consecutivas, gera um alerta. O envio de e-mail só ocorre quando uma integração externa é configurada e o sistema está aberto para processá-lo.

Datas sem lançamento não são tratadas como presença. A regra considera registros diários, não faltas por aula; adapte-a antes de usar em produção.

Publicação, QR Code e alertas

QR Code do endereço do sistema

O QR Code abre a página pública, mas não sincroniza dados entre aparelhos na versão sem servidor. A imagem do QR é gerada por serviço externo e contém apenas o endereço informado.

Serviço de e-mail (EmailJS — opcional)

A integração abaixo faz disparos pelo navegador quando um lançamento ou recálculo gera alerta, somente com a página aberta. Para alertas automáticos contínuos e envio confiável, é obrigatório um backend com banco de dados e tarefa agendada. Não utilize este protótipo com dados pessoais reais.

No template EmailJS, configure os campos {{to_email}}, {{student_name}}, {{consecutive_absences}}, {{message}}. O destinatário do template deve ser {{to_email}}. Serviço externo sujeito a permissões, limites e políticas próprias.

Cópia de segurança local

Backup inclui dados de estudantes e usuários da demonstração. Guarde-o em local restrito. Não publique backups no GitHub.
